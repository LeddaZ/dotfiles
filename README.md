# dotfiles
Various configurations I keep across Linux distros

## Contents
- `.local/share/fonts`: Additional fonts
- `check-updates`: Update checking script for APT and DNF, meant for periodic checks
- `.zshrc`: Zsh config file
- `manage.sh`: Start/stop/pull all Docker Compose services from the current directory
- `zed-settings.json`: My Zed settings
